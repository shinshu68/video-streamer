# 配置・運用 (Windows)

サーバーを Windows 上で動かすための手順と注意点。手順が確定していない項目は「未定」とし、決まり次第更新する。

## 配置

1. WSL 上で Windows 用の exe をクロスビルドする (コマンドは server/CLAUDE.md を参照)
2. exe と設定ファイル (`config.json`) を Windows 側の任意のフォルダに置く (置き場所は未定)
3. 設定ファイルに公開フォルダのパスとポート番号を書く

## 設定ファイル

JSON 形式。既定では exe と同じフォルダの `config.json` を読む。`-config <パス>` で別のファイルを指定できる。ひな形は server/config.example.json。

```json
{
  "root": "E:\\Videos",
  "port": 8765
}
```

| 項目 | 内容 |
| --- | --- |
| `root` | 公開フォルダのパス (外付けHDD上のフォルダ)。JSON のため `\` は `\\` と書く。`/` 区切りでもよい |
| `port` | 待ち受けるポート番号 |

どちらも必須で、欠けている場合は起動時にエラーで終了する。外付けHDDのドライブ文字が変わった場合は、`root` を書き換えて対応する。

## 常駐方法 (未定)

候補は次のとおり。

- スタートアップフォルダに置く: 手軽だが、ログオンするまで起動しない
- タスクスケジューラで起動時に実行する: ログオン前から動かせる
- Windows サービスとして登録する: 安定して常駐できるが、登録に管理者権限が必要

## ファイアウォール

Windows ファイアウォールで、サーバーのポートへの受信をプライベートネットワークに限って許可する。規則の追加には管理者権限が必要。具体的な手順はポート番号が決まったら記載する。

## ffmpeg

サムネイル生成に使う。用意の仕方 (インストールするか、exe と同じ場所に置くか) は未定。

## 運用上の注意

- 外付けHDDがスリープから復帰するまで、最初のアクセスが遅れることがある
- 外付けHDDが接続されていない状態でサーバーが起動した場合の扱いは未定
